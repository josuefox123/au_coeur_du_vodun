# Assets Sprites 2D du Bokonon (Style Jeu Vidéo)

Pour remplacer les placeholders par vos illustrations de jeu vidéo personnalisées :

### Fichiers attendus :
1. `bokonon_idle_1.png` : Bokonon assis en tailleur, yeux mi-clos, respiration haute.
2. `bokonon_idle_2.png` : Bokonon assis en tailleur, respiration basse.
3. `bokonon_throw_1.png` : Bokonon levant le bras avec les cauris dans la main.
4. `bokonon_throw_2.png` : Bokonon projetant les cauris vers le plateau.
5. `bokonon_throw_3.png` : Bokonon bras baissé, cauris éparpillés sur le plateau Opon Ifá.
6. `bokonon_point_1.png` : Bokonon tendant le bras vers l'avant, bouche s'ouvrant.
7. `bokonon_point_2.png` : Bokonon bras tendu en avant en pleine incantation « PORTE, OUVRE-TOI ! ».

### Recommandations techniques :
- **Format** : PNG avec fond transparent (détouré).
- **Dimensions conseillées** : 1024 x 1024 px (ou 512 x 512 px minimum).
- **Cadrage & Point d'ancrage** : Le personnage doit être centré au même endroit sur toutes les images pour que l'animation soit fluide et ne saute pas d'une frame à l'autre.
